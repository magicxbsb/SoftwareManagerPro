# 🚀 Software Manager Pro

> A modern Windows software manager powered by WinGet, Microsoft Store and official vendor sources.

Software Manager Pro is an open-source PowerShell application that allows you to install, update, uninstall and manage Windows software from multiple sources through a modern and modular interface.

---

# ✨ Features

## 📦 Applications

- Install software with WinGet
- Install software from Microsoft Store
- Install software from official vendor websites
- Install drivers and firmware
- Search applications
- Update installed software
- Uninstall software

## ⭐ Favorites

- Save your favorite applications
- Install all favorites with one click

## 👤 Profiles

Create custom installation profiles.

Example:

- Gaming PC
- Streaming PC
- Development PC
- Laptop
- Office

Profiles are stored as JSON files and can be exported or shared.

## 📦 Packs

Install complete software collections.

Examples:

- Gaming
- Streaming
- RGB
- Development
- Audio
- Monitoring
- New PC

## 🔄 Stable / Beta

Choose your preferred release channel.

- Stable
- Beta
- Always Ask

## 🌐 Sources

Supported sources:

- WinGet
- Microsoft Store
- Official vendor websites

## 📝 Logs

Every installation, update or uninstall operation is logged.

## ⚡ Performance

- Application cache
- Installed software cache
- Fast loading
- Modular architecture
